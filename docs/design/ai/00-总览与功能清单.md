# 00 · 总览与功能清单

## 1. 本库说明

本库（`docs/design/ai/`）是 check-manage 平台 AI 能力域的**权威设计文档**：把对话助手、批任务执行引擎、编排与子代理、动作门禁与审批、执行审计、定时扫描、Skill 与 SkillOpt、长期记忆、管理配置、容灾稳定性、开放 API 十二个主题按分册重组，机制描述一律以当前代码为准（证据写 `文件:行` 或符号名）；旧文档（本目录下 `AI*.md`、`SkillOpt*.md` 等）仅代码证实后吸收，并在归档时加横幅指向新分册。

本册（00）是全库索引与**全量功能矩阵**：矩阵初版收录 16 个后端路由文件、27 个 MCP 工具、42 张 AI 表族的覆盖行；后续 12 个分册任务各自向对应锚点（`## 矩阵·01` ~ `## 矩阵·12`）追加本册功能点行。

- **使用者**：`docs/user-guide/ai/`（assistant.md、batch-tasks.md、trace-analysis.md、orchestration.md、long-term-memory.md、scan-tasks.md 等）——本库分册偏设计实现，功能操作看用户指南。

## 4. 状态标记约定

- **已实现**：后端路由/表/工具在代码中存在，且前端有入口（页面/面板/会话 UI）可达。
- **部分**：仅后端实现（有路由/表/工具但无前端入口），或只有部分端点/链路落地。
- **规划**：仅有 spec/设计文档，代码未落地。
- **本册初版口径**：路由/工具/表覆盖行统一标「已实现」（三者都在代码里，证据即上表）；「是否有前端入口」由各分册任务补充功能点行时逐一核对，发现仅后端的覆盖行可在该行改标「部分」并留一句备注。
