# Live2D 智能客服（数字人载体）—— 设计研究

> 状态：脚手架/研究 · 分支 feature/baize-live2d-service
> 背景：原「智能客服」（kefu 实例化 bot）已从产品入口裁剪；能力将由
> Live2D 卡通少女形象承载，半透明悬浮于页面，主动提供使用指导与对话。

## 1. 目标

- 页面右下角半透明 Live2D 少女形象（可拖拽、可最小化）；
- **主动指导**：基于当前页面/操作上下文，时不时推送系统使用提示（防打扰节流）；
- **点击对话**：点击形象展开对话气泡/面板，接入现有 AI 会话能力（白泽大脑）；
- 与既有记忆/权限体系一致：按用户注入记忆，RBAC 约束数据访问。

## 2. 技术选型（研究结论）

| 方案 | 评估 |
|---|---|
| **pixi-live2d-display**（推荐） | 成熟、支持 Cubism 2/4 模型，Vue3 可封装组件；模型文件放 public/models/ |
| live2d-widget | 快速但定制弱、主动指导难做 |
| 自研 WebGL | 成本高不必要 |

对话后端：复用 `kefu` 内部通道（实例=数字人）或直接 `ai_chat` 会话流式接口——
推荐后者（SSE 流式 + 记忆 + 权限已完备），数字人仅是**呈现层**。

## 3. 主动指导策略

- 触发：页面停留 >N 秒、首次进入某管理页、检测到报错 toast；
- 内容：按 route 映射的指导语（可配置于 page_configs/静态 JSON）+ AI 生成兜底；
- 节流：同页同提示每日一次；用户可全局关闭（localStorage）。

## 4. 实施拆分（后续 PR）

1. `BaizeCompanion.vue`：Live2D 容器 + 拖拽/最小化/点击展开；
2. 指导策略服务（前端 composable）+ 提示配置；
3. 对话接入（SSE 流式、上下文注入当前路由）；
4. 模型资产与加载优化（CDN/本地、懒加载）；
5. 客服 kefu 旧通道下线清单（菜单/路由/蓝图标记 deprecated）。
