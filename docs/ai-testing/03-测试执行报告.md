## 2. L3 E2E 明细（e2e/ai-full/，真实链路）

### 2.1 AI 会话（ai-session-core.spec.ts，3/3）
- 创建→发送→**真实 OpenCode 回复**（OK-E2E）服务端落库→前端消息流渲染（截图 `session-core-reply.png`）✅

- clear 原地重置：消息清空、会话保留可续用 ✅
- delete：列表消失、reopen 拒绝（409，软删行保留审计）✅

### 2.2 AI 批任务（ai-batch-lifecycle.spec.ts，2/2）
- 暂存上传→创建 2 文件批任务→侧栏 BatchGroup 分组/展开/子会话（截图 `batch-sidebar-group.png`、`batch-children.png`、`batch-child-conversation.png`）✅
- 子会话完整对话持久化（owner 端读取）✅；批终态收敛（completed）✅
- retry-failed 终态语义（无失败时 `{retried:0}`）✅；终态删除/404 ✅
- 非终态删除 409 + `stop=1` 停止并删除 ✅

### 2.3 AI OpenAPI（ai-openapi.spec.ts，5/5）
- 鉴权矩阵：无/伪造密钥 401；不存在的批任务/会话/扫描任务一律 404（不泄漏存在性）✅
- 路径归属：绝对路径/`..`/他人 staging/伪造路径全部 400 ✅
- 请求体门：`/v1/ai-sessions` >1MB → 413（D3 修复回归）✅
- prompt-templates：重名 409 英文 `name already in use`、缺字段 400 ✅
- memories：空文本/超长 400、删除不存在的 id 不泄漏他人数据 ✅
- 对外单会话：创建（带暂存文件）→ **运行中 output=null（半截输出防泄漏门）** → 完成后 output 非空 ✅
- 对外批任务全生命周期：创建→完成→results（completed 才有 output，MARK 命中）→ **PATCH 整体替换语义**（漏传 model 被清空）→ append 拉回 running（total 3）→ 非终态 retry-failed 409 → 收敛后删除 ✅
- **HMAC 完成回调**：本地 HTTP 接收器验证 `X-Webhook-Event: ai_batch_completed`、`HMAC-SHA256(secret, "{ts}.{body}")` 签名逐字节匹配、secret 不回显 ✅
