## 6. 不变量回归清单（新增功能引入，全量回归必守）

1. 编排定义发布后版本冻结：运行中定义被编辑不影响在途 run；同 id 再发布 version 严格 +1。
2. `single_step` 模式下每次 advance 至多派发 1 个 agent step；auto 模式行为不变（对照）。
3. 编排 step 子会话与批子会话同样遵守门禁 fail-closed：期望不可证实不得 completed。
4. 批子会话永不渲染询问/授权气泡；无人值守 ask 自动拒绝且子任务必收敛。
5. 权限 allow/reject 落库后跨回合生效；「仅本次」仅当前会话生效。
6. MCP 写入/挂菜单工具是唯一写通道（AI 不裸 SQL 直写 dynamic_data/menus）；全部写入有审计。
7. mcp_write 补偿后外部状态与 effect 状态一致（compensated），不产生双写。
8. 画布保存的定义必须通过环/悬空边校验（与 API 直建同规）。
