# 执行审计（管理员）

> 面向：`admin.ai_chat_admin`（查看）· `admin.ai_execution_prompt_read`（Prompt 明文）
> 完整技术细节见 [../../design/AI执行审计能力说明.md](../../design/AI执行审计能力说明.md)

执行审计对每次 AI 执行记录**事实**并给出**确定性判定**：

## 1. 记录什么

- **执行尝试**：每次发送/重试/继续/批任务子会话的 requested vs effective
  Agent/Model、Prompt hash（默认不存明文）、Skill 定义 SHA256、起止时间与错误；
- **不可变事件**：工具状态推进、消息更新、回合收敛等（明文 payload 30 天 / 行 180 天）；
- **定义清单**：本次可见的技能/Agent/指导文件及哈希与注入状态。

## 2. 判定什么

- **契约步骤七态**：已完成（有证据）/ 声称完成（无证据）/ 遗漏 / 顺序错误 /
  失败 / 数据不足——由 Skill 的 `execution_contract`（步骤/依赖/期望工具）与
  实际工具调用、Todo 声明三方比对得出；
- **工具失败**：失败类型（参数/权限/不存在/超时/网络/Provider/…）+ 恢复分析
  （同参重试=无效重试、换策略、是否恢复）；
- **数据完整性**：采集不足时结论自动降级为「数据不足」，不伪造结论。

## 3. 查看入口

- AI 会话管理 → 会话行「执行审计」抽屉；
- API：`/ai/chat/admin/sessions/<sid>/execution-audit` 等见设计文档 §5。

## 4. 权限与安全

- 审计查看需 `admin.ai_chat_admin`；只能查看自己会话（管理员可跨用户）；
- Prompt 明文默认脱敏；查看需要独立权限并记录审计。
