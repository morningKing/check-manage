# 执行审计（管理员）

> 面向：`admin.ai_chat_admin`（「AI 会话治理」，查看）· `admin.ai_execution_prompt_read`（「AI 执行 Prompt 查看」，Prompt 明文）
> 关联：[轨迹分析](./trace-analysis.md) · [AI 会话](./assistant.md) · 完整技术细节见 [AI 设计分册 06 · 执行审计与轨迹分析](../../design/ai/06-执行审计与轨迹分析.md)

执行审计对每次 AI 执行记录**事实**并给出**确定性判定**。

## 1. 记录什么

- **执行尝试（Attempt）**：每次发送/重试/继续/批任务子会话的 requested vs effective
  Agent/Model、Prompt hash（默认不存明文）、Skill 定义 SHA256、起止时间与错误；
- **不可变事件**：工具状态推进、消息更新、回合收敛等（明文 payload 30 天 / 行 180 天）；
- **定义清单**：本次可见的技能/Agent/指导文件及哈希与注入状态。

## 2. 判定什么

- **契约步骤七态**：已完成（有证据）/ 声称完成（无证据）/ 遗漏 / 顺序错误 / 跳过 /
  失败 / 数据不足——由 Skill 的 `execution_contract`（步骤/依赖/期望工具）与
  实际工具调用、Todo 声明三方比对得出；
- **工具失败**：失败类型（参数/权限/不存在/超时/网络/Provider/…）+ 恢复分析
  （同参重试=无效重试、换策略、是否恢复）；
- **数据完整性**：采集不足时结论自动降级为「数据不足」，不伪造结论。

## 3. 查看入口

**设置中心 → AI 能力 → AI 执行中心（「会话审计」页签）**（需 `admin.ai_chat_admin`）：

1. 会话行「操作」下拉 → **执行审计**（或点行打开详情抽屉 → 「执行审计」按钮）；
2. 抽屉（「执行合规审计」）自上而下呈现：
   - **执行尝试**：每次尝试的 Agent/Model（含解析口径）、状态与 Prompt 快照入口；
   - **本次可见的 Agent / Skill 定义**：类型、名称、来源、内容哈希与是否注入；
   - **轨迹分析历史**：由本会话触发的分析会话列表（状态 + 时间），可点「打开会话」回看；
   - **结构化诊断报告**：数据完整性（评分 + 局限说明）、执行契约审计（步骤逐条判定）、
     工具失败（类型 + 恢复分析 + 证据）、Agent 声明计划（Todo，仅自述不作事实）、Prompt 快照；
3. 存在运行中尝试时抽屉每 5 秒自动刷新，回合收敛后呈现最终判定。

Prompt 明文默认脱敏：快照仅显示 hash 与增强项（记忆/附件/@提及）；查看明文需
`admin.ai_execution_prompt_read` 权限且开启明文存储，并记录操作审计。

## 4. 管理员分析闭环（会话审计 → 分析 → 建议反馈）

从「会话审计」页签可以走完一条完整的诊断-改进闭环：

1. **选会话 → 发起分析**：会话行「操作」→ **轨迹分析**（或详情抽屉「轨迹分析」按钮），
   系统创建一个轨迹分析会话并由 `trace-analyzer` 技能异步执行（见 [轨迹分析](./trace-analysis.md)）；
2. **看分析结果**：分析会话产出结构化诊断（根因、契约完成度、优化建议）；
   目标会话的「执行审计」抽屉里 **「轨迹分析历史」** 列出每一次分析，可随时「打开会话」回看；
3. **建议反馈**：对分析给出的优化建议可记录反馈动作
   （采纳 accepted / 拒绝 rejected / 修改 modified / 已应用 applied / 已回滚 rolled_back），
   反馈经执行审计管理接口落库（`/ai/chat/admin/analyses/<分析ID>/suggestions/<建议ID>/feedback`）；
4. **效果追踪**：**设置中心 → AI 能力 → AI 技能（「拟合优化」页签）→ 调用聚合** 的
   「建议效果追踪」表汇总全部反馈；标记「已应用」的建议自动跟踪**前后 7 天窗口**的
   调用成功率对比（应用前 → 应用后），验证建议是否真的有效。

## 5. 权限与安全

- 审计查看需 `admin.ai_chat_admin`；只能查看自己会话（管理员可跨用户）；
- Prompt 明文默认脱敏；查看需要独立权限 `admin.ai_execution_prompt_read` 并记录审计；
- 会话级**尝试时间线**另有只读接口（`/ai/chat/admin/sessions/<会话ID>/attempt-timeline`，
  同样需要 `admin.ai_chat_admin`），返回该会话每次尝试的序号、Agent/Model 解析、
  起止时间、错误与恢复原因，供外部运维工具消费。
