# OpenCode 运行时管理

> **路径**：设置中心 → AI 能力 → **AI 配置（「运行时」页签）**
> **权限**：「AI 配置」入口对持有 `admin.ai_settings` 或 `admin.ai_runtime_read` 的用户可见；「运行时」页签需 `admin.ai_runtime_read`，写操作另有细分权限（见下文）
> **相关设计**：机制细节见设计文档 `docs/design/ai/01-总体架构与运行时.md`、`docs/design/ai/08-Skill与SkillOpt.md`

---

## 这是什么

平台的 AI 会话由 **OpenCode**（`opencode serve` 进程）驱动。OpenCode 在启动时一次性加载全局配置目录（默认 `~/.config/opencode`）下的技能、Agent 与插件，**没有热加载**——改文件后必须重启进程才生效。「运行时」页签就是这个全局配置目录的管理面：直接查看与编辑其中的技能/Agent 文件、掌握「已保存」与「已生效」的差异，并执行应用/重启。

它与 [AI 技能](./skills.md) 的「技能广场」分工不同：**技能广场管理平台技能库**（按会话自动注入、即传即用）；**运行时页签直接管理 OpenCode 全局目录**（对该机器上所有 OpenCode 会话生效、重启生效）。两者互不影响。

## 页面总览与生效状态

页面顶部是一条**状态条**，一眼回答「现在跑着的 OpenCode 用的是不是最新配置」：

- **生效状态**：显示「运行时已生效」，或「N 项已保存待应用」——后者表示有文件改了但进程还没重启加载；
- **serve 健康**：OpenCode 进程是否可达；
- **进程归属**：该端口上的 OpenCode 是**平台启动**的还是外部手动启动的——只有平台托管的进程才允许平台重启。

列表中每条技能/Agent 都带**生效状态**列：

- **已生效**（loaded）：运行中的 serve 已加载该版本；
- **待重启**（pending）：文件已保存，但 serve 尚未加载。

> 注意：**「保存成功」≠「运行时生效」**。文件写入立即落盘，但运行中的 serve 看不到它——必须应用/重启。

## 技能 (Skill) 页签

- **查看与检索**：合并展示「全局目录里的技能文件」与「当前 serve 实际加载的技能」，支持按名称/描述检索；
- **新建 / 上传 / 编辑**：可直接新建技能（名称 + 描述 + 正文），或上传 zip 安装，或在线编辑 SKILL.md 全文；
- **辅助文件编辑**：技能目录下的脚本、模板等文件可在线编辑——**脚本类文件保存后对之后的 Agent 运行即时生效；SKILL.md 变更需重启 OpenCode**；
- **从平台技能库发布**：把 [技能广场](./skills.md) 里的平台技能复制为运行时技能（需 `admin.ai_runtime_publish` 权限）。发布是复制，之后两侧各自演化；
- **删除**：移除该运行时技能。

技能文件的增删改需 `admin.ai_skill_write` 权限。

## 智能体 (Agent) 页签

- 查看/检索 OpenCode 全局目录中的 Agent 定义；
- **新建 / 编辑 / 删除**（需 `admin.ai_agent_write` 权限）；
- **启用 / 禁用**：禁用后重启生效。

## 应用与重启

页面右上提供两个动作：

| 动作 | 权限 | 行为 |
|---|---|---|
| **应用配置**（仅当有待应用项时可用） | `admin.ai_runtime_apply` | 对受管配置做一致性应用；**最终生效仍以重启为准**（OpenCode 无热加载） |
| **重启 OpenCode** | `admin.ai_runtime_restart` | 重启 serve 进程，让所有待应用配置生效 |

重启的两种情形：

- **空闲时**：直接普通重启；
- **有运行中负载时**（还有 AI 会话在跑）：需要 **`admin.ai_runtime_force`**（强制重启）权限才能执行——强制重启会**中断正在运行的回合**。没有该权限时会提示稍后再试。

**进程归属保护**：如果该端口上的 OpenCode 是外部手动启动的（不是平台拉起的），平台**不会**代为重启，页面会提示由运维手动处理——避免误杀不属于平台的进程。

## 常见问题

**改了 SKILL.md / Agent，会话里怎么还是老行为？**
OpenCode 只在启动时加载配置，无热加载。到状态条确认出现「N 项已保存待应用」，点 **应用配置** 后再 **重启 OpenCode**。技能脚本类文件例外——保存后对之后的运行即时生效。

**状态条显示「运行时已生效」但我刚改过文件？**
刷新页面重新读取状态；若确认已保存，检查是否看的是另一个文件（全局目录技能与平台技能库是两套，见 [AI 技能](./skills.md)）。

**重启按钮点了没反应/被拒绝？**
两种可能：缺少 `admin.ai_runtime_restart` 权限；或当前有运行中的会话而你无 `admin.ai_runtime_force`——等运行中的任务收敛后再重启，或找持有强制权限的管理员。

**端口上的 OpenCode 不是平台启动的，平台能管吗？**
文件视图仍可查看，但平台不会代启代停（防止误杀外部进程）。需要运维手动接管该进程后，再改由平台托管。
