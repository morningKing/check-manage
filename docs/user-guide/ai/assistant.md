# AI 会话（AI 助手）

> 面向：所有登录用户 · 关联：[会话分组与归档](./session-groups.md) · [长期记忆](./long-term-memory.md) · [轨迹分析](./trace-analysis.md)

AI 会话是与 **白泽** AI 助手交互的主入口：通过顶部导航 **「AI 助手」** 进入全屏对话页，
左侧为会话/分组/批任务侧栏，右侧为对话流、工具调用气泡、执行计划与文件产物，
底部为输入区（模型/Agent 可选）。

AI 底层由 **OpenCode** 智能体运行时驱动，可经 MCP Server 调用平台数据
（受与前端一致的 RBAC 约束），协助数据问答、脚本开发、文档生成与长任务执行。

## 1. 开始与发送

1. 顶部导航 **AI 助手** 进入对话页（左侧「会话」分组，点「新建会话」创建）；
2. 输入框输入内容：`Enter` 发送、`Shift+Enter` 换行；
3. 回复流式呈现；AI 的**工具调用**以摘要气泡展示（操作 · 结果 · 耗时 · 状态文字），
   点击展开原始输入/输出；
4. **@提及**：`@文件路径` 内联文件内容；`@子智能体` 委托子代理执行
   （委托气泡可展开查看子代理完整轨迹）；
5. **附件**：上传文件后内容自动内联给 AI；
6. **执行计划**：多步任务时 AI 会用 Todo 工具规划，实时展示每步状态与进度。

## 2. 运行中交互与队列

- 回合进行中仍可继续发送：消息标记「排队中」，回合结束自动发出；
- `/` 命令面板支持 OpenCode 命令与平台技能（如 `/compact` 压缩上下文）。

## 3. 失败与断线（自动恢复）

- **发送失败**：出现错误卡（错误原因 + 原始输入），点「重试本轮」一键重试，
  服务端孤儿消息会被自动清理；
- **断线重连**：连接断开自动重连，并以服务端状态为准收敛——不会停留在“正在回复”。

## 4. 产物与文件

- AI 产出的文件（outputs/）在消息流「文件」卡片中预览/下载；
- 上传文件在 uploads/ 分组管理；
- Git 变更视图展示 AI 修改的文件与 diff。

## 5. 会话管理

| 操作 | 说明 |
|---|---|
| 重命名 / 关闭 / 清空 / 删除 | 会话行图标操作 |
| 分组与归档 | 见 [会话分组与归档](./session-groups.md) |
| 轨迹分析 | 管理员对任意会话发起审计分析，见 [轨迹分析](./trace-analysis.md) |

## 6. 模型与 Agent

- 输入区可选择模型（provider/model）与 Agent（含 @子智能体提及）；
- 选择按会话记忆（localStorage），下次打开自动恢复。
