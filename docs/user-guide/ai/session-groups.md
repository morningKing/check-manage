# 会话分组与归档

> 面向：所有登录用户（轨迹分析分组为管理员）

AI 助手侧栏「会话」分组支持**自定义分组**，并内置**轨迹分析**系统分组——
普通会话与轨迹分析会话分组展示、互不混排。

## 1. 侧栏结构

```text
会话
 ├─ 未分组会话（新会话默认落这里）
 ├─ ▾ 你的自定义分组（可多个，折叠状态记忆）
 ├─ ▸ 轨迹分析 (N)        ← 系统分组（管理员触发分析后生成，不可移动/删除）
批任务 / AI定时任务
```

## 2. 自定义分组操作

| 操作 | 入口 | 说明 |
|---|---|---|
| 新建分组 | 「会话」标题旁 **分组** 按钮 | 名称 ≤ 50 字 |
| 移动会话 | 会话行 hover 📁「移动到分组」 | 序号菜单；支持「＋ 新建分组…」就地创建并移入 |
| 折叠/展开 | 分组头点击 | 状态本地记忆 |
| 重命名 | 分组头 hover ✏️ | — |
| 删除分组 | 分组头 hover 🗑 | **会话不会被删除**，全部回到未分组 |

- 同名分组不可重复；未分组会话始终显示在分组之前；
- 删除分组不会误删会话——这是归档安全性的关键设计。

## 3. 存量自动归档（惰性初始化）

首次进入 AI 助手时，若你**从未建过分组**且存在 ≥15 个未分组会话，
系统会自动创建一个「**历史会话**」分组并把存量会话全部收纳：

- 分组可重命名（如改为「项目 A 存量」）、可删除（会话回未分组）；
- 该初始化是幂等的：删除全部分组后再次进入满足条件时会重新触发。

## 4. 轨迹分析系统分组

- 管理员在「AI 会话管理」对任意会话发起**轨迹分析**后生成；
- 默认**折叠**展示、独立图标与样式，与普通会话互不混排；
- 点击可打开分析会话，顶部横幅显示**原会话 ID**并可跳转会话管理；
- 该分组为系统分组：不可移动到自定义分组、不可被自定义分组操作影响；
- 管理端「AI 会话管理」默认同样隐藏分析会话，勾选「显示轨迹分析会话」可见。

## 5. 数据口径

- 分组数据存储于 `ai_chat_session_groups`，会话归属字段
  `ai_chat_sessions.group_id`（删组时置 NULL，会话不删）；
- 轨迹分析会话由 `kind = 'trace_analysis'` 标识，独立于自定义分组体系。
