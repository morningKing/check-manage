# AI 建表

在 **设置中心 → 页面配置**（`/admin/page-config`）点击左上角「**AI 建表**」，用一句自然语言描述一个业务实体，AI 会草拟出字段列表、API 端点和页面路由，确认后**一次性创建好页面配置和菜单**——不用再手动一个字段一个字段地添加，也不用再单独去「菜单管理」挂菜单。需要 `admin.page_configs` 权限（跟手动新增页面配置同一个权限门）。

## 使用步骤

1. 进入 **设置中心 → 页面配置**，点击「AI 建表」。
2. **描述**你想创建的数据表，例如："我要创建一张订货表，记录客户、商品、数量、单价、下单日期和订单状态"。描述越具体，AI 生成的字段越贴合需求。
3. **挂载到项目**：选择新页面要挂在哪个项目菜单下——这一步必须手动选，AI 不知道系统里已有哪些项目。
4. 点击「生成」。AI 会返回一份草案，展开预览界面。
5. **检查并编辑预览**（生成结果全部可改，确认前不会写入数据库）：
   - 页面名称 / 描述
   - **集合标识**（决定实际的 API 端点 `/<集合标识>`）——如果这个标识已经被别的页面占用，会有醒目提示，需要改成别的标识才能继续
   - 菜单名称 / 路由路径
   - **字段表格**：字段名、显示名称、控件类型、是否必填；下拉/多选/单选/复选类型的字段还可以编辑选项（格式 `标签1:值1, 标签2:值2`）；可以增删字段行
6. 点击「确认创建」。

创建成功后，左侧页面列表会出现新页面，对应项目的侧边栏下也会出现新菜单项，点开即可直接使用——包括表格视图和录入表单。

## AI 不会生成哪些字段

为了保证生成结果一定能直接落库、不需要额外校验修复，AI 被限定只生成这些控件类型：单行文本、多行文本、Markdown、富文本、数字、单选下拉、多选下拉、单选按钮、复选框、日期、日期时间、文件、图片、自动时间戳、自增序列。

**不会生成**：关联（relation）、数据引用（reference）、引用选择（quoteSelect）——这三种需要指定系统里已存在的目标集合，AI 无从得知；也不会生成状态徽标（statusBadge）、组合文本（compositeText）——配置项较重，不适合作为首版草案。

需要这些能力，请在创建完成后，到该页面的「字段配置」标签页手动添加。

## 失败与异常情况

- **AI 功能未启用 / 未配置 API Key**：生成时会提示"AI 建表功能未启用"或"AI 服务未配置 API Key"，需要先在 **设置中心 → AI 配置** 里开启并填好密钥。
- **AI 返回内容无法使用**：极少数情况下 AI 可能返回不完整或格式错误的结果，此时会提示错误并停留在描述输入界面，可以换一种描述再试一次。
- **页面创建成功但菜单挂载失败**（通常是当前角色没有「菜单管理」权限）：预览界面会保留提示，说明页面已经创建成功（左侧列表里能看到），需要请有权限的管理员到「菜单管理」里为这个页面手动补一条菜单——不会因为菜单挂载失败就把已创建的页面回滚删除。

## 与手动创建的关系

AI 建表只是新增页面配置 + 菜单的一条快捷路径，跟手动在「页面配置」点「新增」、逐个字段配置，再到「菜单管理」手动挂菜单，效果完全等价——生成的页面配置和菜单是普通数据，后续可以照常在「页面配置」「菜单管理」里编辑、调整。
